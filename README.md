# 台割作成

冊子・パンフレットの台割（ページ割り）をブラウザで作成するツールです。
`index.html` をブラウザで開くだけで使えます。

## 機能

- 見開き単位の台割表（A4横）を自動レイアウト。1行の見開き数は設定で変更可
- ページごとに「上段」「下段」の内容と区分（継続／新規・再編集／共通／検討中）、メモを設定
- 同じ内容・区分が続くページは1本の帯にまとめて表示
- 台割上でクリック（Shift＋クリックで範囲）選択し、まとめて内容を設定
- ページ一覧で1ページずつ直接入力
- 2ページ単位の挿入・削除（以降のページ番号は自動で繰り上げ／繰り下げ）
- ページごとに画像（サムネイル）を設定。見開き2ページに横長画像を設定すると左右に分割
- 表紙は「なし／H1・H4／表1〜表4」から選択（表記は H1〜H4 または 表1〜表4）
- 左開き（横組み）・右開き（縦組み）に対応。右開きは右上から左へ並べて表示
- 本文ページ数、1行の見開き数、1枚あたりの行数、文字サイズ（標準／大／特大）、仕様・備考、凡例の文言を設定。合計が4の倍数でない場合は警告
- 行数が多い台割は複数枚に分けて印刷・PowerPoint出力
- **Excel読込**：「ページ」「タイトル」の見出し行がある1行1ページの台割表（.xlsx）から台割を作成（下記）
- 元に戻す（Ctrl+Z）、ブラウザへの自動保存（localStorage）、JSON での保存・読込
- 印刷 / PDF 保存（A4横。「一覧も印刷」でページ一覧を2ページ目以降に出力）
- PowerPoint（.pptx）出力（A4横・1枚。メモはノートにも出力。※インターネット接続が必要）
- 「サンプルを読込」で2028パンフの台割（巻頭にトピックス2ページを追加する案）を表示

## Excel読込のルール

- Excelファイルは複数まとめて選べます。全シートのうち**日付がいちばん新しいシート**を自動で読み込みます
  （シート名・ファイル名の日付 例：`0908`・`260831`・`2026/09/08` で判定）。台割の日付もその日付になります
- 読み込んだシートは画面上部に表示。「別のシートを選ぶ」で、日付の新しい順に並んだシートから選び直せます
- 見出し行：「ページ」（または 頁・P・No）の列と「タイトル」（または 内容・項目・見出し）の列がある行
- ページ列：数字は本文ページ、「表1〜表4」「H1〜H4」は表紙。ページ番号の重複・逆順は直前の番号＋1として読み込み、注意に表示
- 「第○章／部／編」で始まるタイトルは章として上段の帯になり、そのページは下段が「扉」になります
- タイトルが空欄または「↓」のページは、前のページの続きとして同じ帯にまとめます
- 「【新規】」を含むタイトルは赤（新規）、「●」「？」「未定」を含むタイトルは水色（未確定）で表示
- 上記以外の列（概要・撮影・担当・進行状況など）は「見出し：値」の形でメモに入ります
- 見出し行より上のセルから、タイトル・仕様（判型など）・「右開き／左開き」を読み取ります（シート名などに日付がない場合は「○○版」の日付を使用）
- 読み込み後は文字が読みやすいよう「1行7見開き×5行・文字サイズ 大」で表示し、入りきらない分は2枚目以降に分けます（設定で変更可）
